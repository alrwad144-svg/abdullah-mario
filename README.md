# 🍄 سوبر ماريو - Super Mario Bros

لعبة ماريو كلاسيكية مبنية بـ HTML5 و Canvas و JavaScript!

![Mario Game](https://img.shields.io/badge/Platform-Web-blue) ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

---

## 🎮 كيفية اللعب

| المفتاح | الوظيفة |
|---------|---------|
| `←` `→` | التحرك لليمين واليسار |
| `Space` / `↑` | القفز |
| `R` | إعادة اللعبة |

### 📱 الموبايل
تتوفر أزرار تحكم تلقائية على الشاشات الصغيرة.

---

## ⭐ مميزات اللعبة

- 🎨 تصميم بصرية مميز مع خلفيات متعددة الطبقات (Parallax)
- 🪙 **20 عملة ذهبية** لجمعها
- 🐛 **6 أعداء (غومبا)** للقضاء عليهم
- 🧱 مراوح عائمة وأنابيب وأرضية
- 🎆 تأثيرات جسيمات تفاعلية
- 🏁 علم الوصول كهدف نهائي
- 📱 متوافقة مع الموبايل
- 🎬 شاشة بداية مميزة بتأثيرات بصرية

## 🚀 كيف تشغل اللعبة

1. حمّل الملف `mario.html`
2. افتحه في أي متصفح (Chrome, Edge, Firefox)
3. اضغط **"ابدأ اللعب!"**
4. استمتع! 🎉
