# 🍄 سوبر ماريو - Super Mario Bros

لعبة منصات كلاسيكية كاملة مبنية بـ HTML5 و Canvas و JavaScript — ملف واحد فقط!

## 🎮 كيفية اللعب

| المفتاح | الوظيفة |
|---------|---------|
| `←` `→` (أو `A` `D`) | التحرك يميناً ويساراً |
| `Space` / `↑` | القفز (استمر بالضغط لقفزة أعلى) |
| `Shift` | الجري السريع |
| `X` | رمي كرة نار (بعد أخذ زهرة النار) |
| `↓` | الانحناء (وأنت كبير) |
| `P` أو `Esc` | إيقاف مؤقت |
| `M` | كتم/تشغيل الصوت |
| `F` | ملء الشاشة |
| `R` | إعادة اللعبة |
| `Enter` | متابعة بعد إنهاء المرحلة |

### 📱 الموبايل
أزرار لمس تلقائية على الشاشات الصغيرة: حركة، قفز، وزر 🔥 للجري ورمي النار.

## ⭐ المميزات

### 🗺️ خمس مراحل كاملة بسمات مختلفة
| المرحلة | الاسم | السمة |
|---------|-------|-------|
| 1-1 | السهول الخضراء | نهار، تلال، أنابيب |
| 1-2 | الكهوف المظلمة | سقف، طوب أزرق، مصاعد |
| 1-3 | سماء النجوم | ليل، قمر، منصات سحاب ومنصات متحركة |
| 1-4 | قلعة الحمم | حمم، أشواك، أعمدة |
| 1-5 | 🔥 معركة باوزر 🔥 | قلعة، جسر فوق نهر حمم، وزعيم نهائي |

### 🍄 القوى والعناصر
- **الفطر الأحمر**: يكبّرك ويحميك من ضربة واحدة
- **زهرة النار**: ارمِ كرات نار مرتدة تقتل الأعداء
- **النجمة**: حصانة كاملة بألوان قوس قزح لمدة 10 ثوانٍ
- **الفطر الأخضر (1UP)**: حياة إضافية
- **صناديق الأسئلة `؟`**: عملات وقوى مخفية
- **الطوب القابل للكسر**: اكسره وأنت كبير، أو اضربه من الأسفل لقلب الأعداء فوقه

### 👾 الأعداء
- **غومبا**: ادُس عليه
- **كوبا**: ادُسه فيتحول لصدفة — اركلها لتقتل كل من في طريقها (نقاط متضاعفة!)
- **الشوكي**: لا يُداس — تجاوزه قفزاً أو اقتله بالنار/الصدفة
- **الطائر**: يطير بموجة جيبية
- **🔥 باوزر (الزعيم النهائي)**: 5 قلوب، يمشي على الجسر ويرمي كرات نار موجهة نحوك، وكلما نقصت صحته زاد غضبه وسرعته. لا يُداس ولا تقتله الصدفة — فقط كرات نارك (أو لمس النجمة) تسقطه. اسقطه لتفوز باللعبة!

### ⚙️ محرك فيزياء حقيقي
- تسارع واحتكاك وقفز متغيّر الارتفاع (اضغط مطولاً = قفزة أعلى)
- Coyote time و Jump buffering لإحساس تحكم دقيق
- تصادم بلاطات كامل (جوانب، رؤوس، منصات أحادية الاتجاه)
- منصات متحركة أفقية ورأسية تحمل ماريو
- كاميرا ناعمة مع اهتزاز شاشة عند الأحداث الكبيرة

### 🔊 صوت وموسيقى
مؤثرات وموسيقى خلفية مولّدة بالكامل عبر Web Audio API (بدون ملفات):
قفز، عملات، دوس، كسر طوب، قوى، موت، علم، وألعاب نارية — مع لحن مختلف لكل سمة.

### 💾 حفظ تلقائي
أفضل نتيجة وآخر مرحلة مفتوحة تُحفظ في المتصفح (localStorage)، مع اختيار المرحلة من شاشة البداية.

## 🛠️ التقنيات المستخدمة

- **HTML5 / CSS3** — الهيكل والتصميم وشاشة البداية
- **Canvas API** — رسم كل عناصر اللعبة ببكسلات مرسومة برمجياً (بدون صور خارجية)
- **JavaScript (Vanilla)** — محرك اللعبة: فيزياء، تصادم، ذكاء أعداء، جسيمات
- **Web Audio API** — توليد المؤثرات والموسيقى برمجياً
- **localStorage** — حفظ أفضل نتيجة والمراحل المفتوحة

## 🚀 كيف تشغل اللعبة

1. حمّل الملف `mario.html`
2. افتحه في أي متصفح (Chrome, Edge, Firefox)
3. اختر المرحلة واضغط **"ابدأ اللعب!"**
4. استمتع! 🎉

> لا يحتاج سيرفر ولا اتصال إنترنت (خط Cairo فقط للزينة، واللعبة تعمل بدونه).
